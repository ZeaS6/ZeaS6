## 👋 About Me

I am a Mathematics with Computer Science student at **King Mongkut's University of Technology North Bangkok (KMUTNB)**, with an interest in technology, artificial intelligence, and data analytics.

My academic background and project experience involve developing software solutions, applying machine learning techniques, and working with data to solve real-world problems.

### 💻 Project Experience

My work involves developing an **AI-Based Suspicious Behavior Detection and Alert System** using YOLOv11 and Computer Vision. The system is designed to analyze CCTV footage, detect suspicious activities in gold shops, and generate alerts to improve security monitoring.

Key areas of work include:
- AI Model Development and Training using YOLOv11
- Image Annotation and Dataset Preparation with Roboflow
- Computer Vision and Video Processing with OpenCV
- CCTV Integration and Real-Time Object Detection
- Alert System Development

### 📊 Areas of Interest
